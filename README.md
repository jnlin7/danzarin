# 기록의 온도 — 개인 블로그 & 프로필 웹사이트

Google Apps Script와 구글 스프레드시트를 데이터베이스(DB)로 활용하는 개인 블로그 및 포트폴리오 웹사이트입니다.

---

## 1. 프로젝트 개요

- **사이트명**: 기록의 온도
- **기능 범위**: 회원가입, 로그인/로그아웃, 사용자 프로필, 게시글 목록(검색·필터링·더보기), 게시글 상세 보기(좋아요·공유), 새 글 작성(마크다운 서식·자동 임시저장)
- **백엔드/DB**: Google Apps Script(GAS) Web App + Google Sheets (회원 및 세션 데이터베이스)
- **프론트엔드**: HTML5, CSS3(반응형), Vanilla JavaScript

---

## 2. 페이지 구성

| 페이지 | 파일명 | 주요 기능 |
| :--- | :--- | :--- |
| **게시글 목록** | `index.html` | 카테고리 탭(개발/생각/일상), 실시간 검색, 글 더보기, 인기 글, 사이드바 작가 소개 |
| **게시글 상세** | `post-detail.html` | 게시글 전문, 반응형 레이아웃, 하트 좋아요 토글, URL 링크 복사, 목차(TOC) |
| **게시글 작성** | `write.html` | 제목/카테고리/요약/본문 입력, 서식 툴바(굵게/기울임/제목/인용/코드), `localStorage` 자동 임시저장 |
| **프로필 소개** | `profile.html` | 작가 소개, 주요 경력 타임라인, 관심 분야 태그, 소셜 링크 |
| **로그인** | `login.html` | 이메일/비밀번호 로그인, 비밀번호 보기 토글, 자동 로그인 유지, 구글 시트 DB 세션 인증 |
| **회원가입** | `signup.html` | 이름, 필명, 이메일, 비밀번호 검증, 구글 시트 DB 연동 회원 등록 |

## 3. 구글 스프레드시트 DB 설정 안내

프로젝트의 `apps-script/` 폴더에 구글 스프레드시트와 연동되는 백엔드 코드가 준비되어 있습니다.

### 설정 순서

1. **구글 스프레드시트 생성**: 새 구글 스프레드시트를 생성합니다.
2. **Apps Script 열기**: 스프레드시트 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
3. **코드 붙여넣기**: `apps-script/Code.gs` 파일의 전체 내용을 Apps Script 편집기에 붙여넣습니다.
4. **시트 초기화 실행**:
   - 편집기 상단 함수 선택창에서 `setupAuth`를 선택하고 **실행** 버튼을 누릅니다.
   - Google 계정 권한 승인 팝업이 뜨면 권한을 허용합니다.
   - 실행 완료 후 스프레드시트에 `Users` 시트(회원 DB)와 `Sessions` 시트(세션 DB)가 자동 생성됩니다.
5. **웹 앱 배포**:
   - 우측 상단 **배포 → 새 배포**를 클릭합니다.
   - 유형 선택: **웹 앱**
   - 실행 사용자: **나(Me)**
   - 액세스 권한이 있는 사용자: **모든 사용자(Anyone)**
   - **배포** 버튼을 누르고 발급된 웹 앱 URL(`/exec`로 끝남)을 복사합니다.
6. **프론트엔드 연동**:
   - `js/main.js` 파일 첫 줄의 `AUTH_API_URL` 변수에 복사한 웹 앱 URL을 지정합니다.
   ```javascript
   const AUTH_API_URL = "여기에_발급받은_배포_URL_붙여넣기";
   ```

---

## 4. 로컬 및 GitHub Pages 배포

- **로컬 실행**: `index.html` 파일을 더블 클릭하거나 VS Code의 Live Server로 실행합니다.
- **GitHub Pages**: 저장소의 `Settings → Pages`에서 `main` 브랜치, `/(root)`를 지정하면 배포됩니다.
